*** authorized-update-document
:PROPERTIES:
:KIND: fn
:PACKAGE: STAR.AUTHORIZATION
:END:
#+begin_src common-lisp
(authorized-update-document (STAR.AUTHORIZATION::DOCUMENT-ID STAR.AUTHORIZATION::PATCH
 STAR.AUTHORIZATION::FETCH-FN STAR.AUTHORIZATION::UPDATE-FN &KEY
 STAR.AUTHORIZATION::PRINCIPAL STAR.AUTHORIZATION::METADATA))
#+end_src
Authorize an update against the current document before persistence.

FETCH-FN returns the current document or NIL for an insert candidate. UPDATE-FN
receives PATCH only after the resource decision has been made.
