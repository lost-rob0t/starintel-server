* Types and Classes
*** pattern
:PROPERTIES:
:KIND: class
:PACKAGE: STAR.ACTORS.MATCHER
:END:
Document pattern matcher, based on a match-fn you supply. When the handler returns non nill, the subs actors are then sent a message with the message being the document
- Slots: =name=, =transient=, =match-fn=, =subs=
