The ~couchdb-agent-delete~ function is calling ~cl-couch:delete-document~ with only 3 arguments (client, database, document-id), but the cl-couch library requires 4 arguments (client, database, id, rev).

*** Error Message
#+begin_example
[http-tests] Error deleting document: invalid number of arguments: 4
#+end_example

*** Current Implementation (BROKEN) - source/actors.lisp:85-87
#+begin_src lisp
(defun couchdb-agent-delete (agent database document-id)
  (anypool:with-connection (client (couchdb-agent-client agent))
    (cl-couch:delete-document client database document-id)))
#+end_src

*** Actual cl-couch Signature - /home/unseen/common-lisp/cl-couch/couch.lisp:527
#+begin_src lisp
(defmethod delete-document ((client couchdb-client) database id rev)
  (couchdb-request client
                   (quri:make-uri :path (format nil "/~a/~a" database id)
                                  :query (quri:url-encode-params (safe-alist `((rev . ,rev)))))
                   :method :delete))
#+end_src

The revision parameter is REQUIRED by CouchDB's REST API for document deletion to prevent conflicts.

*** Correct Implementation Pattern
See ~source/frontends/http-api.lisp:199-208~ and ~t/http-api-test.lisp:271-287~ for examples of correct usage:

1. Fetch the document to get its current revision
2. Parse the document JSON to extract ~_rev~
3. Call ~delete-document~ with all 4 required arguments

#+begin_src lisp
(defun couchdb-agent-delete (agent database document-id)
  (anypool:with-connection (client (couchdb-agent-client agent))
    (let* ((doc (cl-couch:get-document client database document-id))
           (parsed-doc (jsown:parse doc))
           (rev (jsown:val parsed-doc "_rev")))
      (cl-couch:delete-document client database document-id rev))))
#+end_src

*** Root Cause
The bug is in the starintel-server codebase, NOT in cl-couch. The cl-couch library correctly requires a revision parameter (as per CouchDB's REST API), but ~couchdb-agent-delete~ is not fetching the revision before attempting deletion.

*** Impact
- Any code calling ~couchdb-agent-delete~ will fail with "invalid number of arguments: 4" error
- This affects document deletion functionality throughout the actor system
- HTTP API delete endpoint works correctly because it fetches revision first
